# Скриншоты для презентации

Сохраните PNG-файлы в папку **`presentation/screenshots/`** с такими именами:

| Файл | Что снять |
|------|-----------|
| `00-overview.png` | Шапка сайта с меню (любая страница) |
| `01-index.png` | Главная: hero + начало страницы |
| `02-catalog.png` | Страница «Традиции», несколько карточек |
| `03-map.png` | Карта с маркерами и фильтрами |
| `04-media.png` | Медиатека (три категории) |
| `05-audio.png` | Аудиогид со списком мантр |
| `06-kalm.png` | Раздел «Калмыкия» |
| `07-chat.png` | Открытый AI-чат (по желанию) |
| `08-mobile.png` | Главная в режиме телефона (F12 → iPhone) |

## Как сделать скрин

1. Откройте **https://hidas0.github.io/Buddhist/** (или локально через Live Server).
2. **Win + Shift + S** (Windows) или **Cmd + Shift + 4** (Mac).
3. Сохраните в `presentation/screenshots/` с именем из таблицы.
4. Откройте **`presentation/index.html`** в браузере — картинки появятся на слайдах автоматически.

## Показ презентации

- Откройте `presentation/index.html` двойным щелчком или через локальный сервер.
- **Стрелки** / **пробел** — следующий слайд.
- **F** — полный экран.
- **Esc** — обзор всех слайдов.

## В PowerPoint

Можно перенести скрины и текст со слайдов вручную или экспортировать PDF из браузера (Печать → Сохранить как PDF).
