# Путь Дхармы

Образовательный портал по теме **«Традиции и обычаи буддийских народов»**: каталог практик и ритуалов, этнокультурный раздел о Калмыкии, карта святынь, медиа и аудио, справочный блок об основах учения, AI-наставник.

**Опубликован:** https://hidas0.github.io/Buddhist/

**Инструкция по сайту:** [ИНСТРУКЦИЯ.txt](ИНСТРУКЦИЯ.txt)

## Разделы

| Страница | Содержание |
|----------|------------|
| `index.html` | Главная, блоки о Дхарме, карусель 14 Далай-лам |
| `catalog.html` | Традиции, ритуалы, народы и регионы, священные места |
| `map.html` | Карта святынь (Leaflet) |
| `media.html`, `video-player.html` | Видеотека из облака; каталог роликов — блок `DHARMA_VIDEO_CATALOG` в `video-player.html` |
| `audio.html` | Аудиогид, мантры |
| `kalm.html` | Буддизм в Калмыкии |

## Технологии

HTML, CSS, JavaScript без backend. Деплой на **GitHub Pages** (workflow в `.github/workflows/pages.yml`). Видео и аудио отдаются с **Yandex Object Storage**; изображения — в `images/`. AI-чат — **OpenRouter** (`js/ai-chatbot.js`).

## Структура

```
css/          — стили (в начале файла — оглавление секций)
js/           — скрипты; см. js/README.md (порядок подключения, AI, лотосы)
images/       — иллюстрации
data/         — places.json для карты
```

В коде добавлены комментарии: **`css/style.css`** — палитра в `:root` (какой цвет за что), оглавление секций; **`js/README.md`** — скрипты; подсказки в HTML и ключевых функциях.

Папки `video/` и `audio/` в репозитории не хранятся (тяжёлые файлы в облаке). Ключ OpenRouter — в `js/config.local.js` (файл в `.gitignore`; для продакшена подставляется из секрета `OPENROUTER_API_KEY` при сборке).

## Локальный запуск

Откройте проект через локальный сервер (Live Server, `npx serve` и т.п.), не как `file://`. Для работы чата локально скопируйте `js/config.local.js.example` → `js/config.local.js` и укажите ключ с [openrouter.ai](https://openrouter.ai).

## Синхронизация с GitHub

- После работы агента в Cursor изменения **автоматически** коммитятся и отправляются на `origin/main` (хук `.cursor/hooks/git-sync.ps1`).
- Вручную: `powershell -File scripts/git-push.ps1 -Message "описание изменений"`.
- Папки `video/` и `audio/` в репозиторий не попадают (см. `.gitignore`) — файлы хранятся в облаке.
