# Инструкция по сайту «Путь Дхармы»

Образовательный статический портал о **традициях и обычаях буддийских народов**.  
Публичная версия: **https://hidas0.github.io/Buddhist/**  
Репозиторий: **https://github.com/Hidas0/Buddhist**

Краткое описание — в [README.md](README.md). Детали по скриптам — в [js/README.md](js/README.md).

---

## 1. Структура проекта

```
public/                          ← корень сайта (эта папка)
├── index.html                   главная
├── catalog.html                 каталог традиций и ритуалов
├── map.html                     карта святынь
├── media.html                   раздел «Медиа»
├── video-player.html            видеотека (плейлисты из облака)
├── audio.html                   аудиогид, мантры
├── kalm.html                    буддизм в Калмыкии
├── css/style.css                все стили (оглавление в начале файла)
├── js/                          скрипты (см. js/README.md)
├── images/                      картинки (hero, далай-ламы, иллюстрации)
├── data/
│   ├── places.json              точки на карте
│   └── place-images.json        доп. фото мест (при необходимости)
├── .github/workflows/pages.yml  деплой на GitHub Pages
├── scripts/git-push.ps1         ручная отправка в Git
└── ИНСТРУКЦИЯ.md                этот файл
```

**Не хранятся в Git** (см. `.gitignore`):

| Путь | Причина |
|------|---------|
| `video/`, `audio/` | Тяжёлые файлы лежат в **Yandex Object Storage** |
| `js/config.local.js` | Секретный ключ OpenRouter для AI-чата |

## 2. Страницы и что на них редактировать

| Страница | Основной контент | Где править |
|----------|-----------------|-------------|
| `index.html` | Hero, блоки о Дхарме, маршрут изучения, цитаты, карусель Далай-лам | HTML + `js/dalai-carousel.js` (тексты слайдов) + `images/dalai-lamas/` |
| `catalog.html` | Категории: медитация, ритуалы, паломничество, праздники, мантры, народы | HTML-секции с `id="catalog-…"`; фильтры — `js/catalog.js` |
| `map.html` | Яндекс.Карта, список мест, таймлайн эпох | `data/places.json`, логика — `js/map-page.js` |
| `media.html` | Превью разделов медиа | `media.html`, при необходимости `js/media-page.js` |
| `video-player.html` | Каталог роликов по темам | Блок `window.DHARMA_VIDEO_CATALOG` в `<script>` на странице |
| `audio.html` | Список мантр и нижний плеер | Массив треков в `<script>` на странице; URL — облако |
| `kalm.html` | История, форум «Сансара», праздники | `kalm.html` (длинная вёрстка) |

На **всех** страницах общие элементы:

- шапка `.navbar` и мобильное меню (`data-mobile-nav-*`);
- подвал с цитатой (на главной — случайная из массива в `index.html`);
- фоновые лотосы — `js/lotus-bg.js` (подключается почти везде);
- чат ИИ — `js/ai-chatbot.js` + ключ в `js/config.local.js`;
- кнопка «Наверх» — `js/back-to-top.js` (`#backTopBtn`).

## 3. Локальный запуск

1. Клонируйте репозиторий или откройте папку `public`.
2. Запустите **локальный HTTP-сервер** (не открывайте HTML как `file://` — карта, чат и часть скриптов могут не работать):

   ```powershell
   npx serve .
   ```

   Либо расширение **Live Server** в VS Code / Cursor.

3. Откройте в браузере адрес сервера (например `http://127.0.0.1:3000`).

### AI-чат локально

```text
js/config.local.js.example  →  скопировать в  js/config.local.js
```

Вставьте ключ с [openrouter.ai/keys](https://openrouter.ai/keys) (формат `sk-or-v1-…`).

В HTML файл `config.local.js` должен идти **перед** `ai-chatbot.js`, **без** атрибута `defer`.

## 4. Публикация на GitHub Pages

- Ветка **`main`**: при каждом push срабатывает workflow `.github/workflows/pages.yml`.
- Сайт собирается как статика из корня репозитория (без сборщика).
- Базовый URL: `https://hidas0.github.io/Buddhist/` — учтён в `js/site-config.js` для заголовков OpenRouter.

### Ключ AI на продакшене

В настройках репозитория GitHub → **Secrets** → `OPENROUTER_API_KEY`.  
При деплое CI создаёт `js/config.local.js` с `window.DHARMA_OPENROUTER_KEY`.  
Без секрета чат на сайте покажет подсказку о необходимости ключа.

### Ручная отправка изменений

```powershell
powershell -File scripts/git-push.ps1 -Message "описание изменений"
```

В Cursor после правок агента может срабатывать автосинхронизация (`.cursor/hooks/git-sync.ps1`).

## 5. Типовые задачи редактирования

### 5.1. Изменить текст или блок на странице

1. Откройте нужный `.html`.
2. Найдите секцию по заголовку или `id` / `class` (в `catalog.html` — `category-section`, якоря `#catalog-meditation` и т.д.).
3. Сохраните и обновите страницу в браузере.

Подсказки по разметке часто есть в HTML-комментариях.

### 5.2. Цвета и внешний вид

Файл **`css/style.css`**:

- палитра в `:root` (`--primary`, `--bg`, `--secondary`, …);
- оглавление секций в шапке файла (navbar, hero, catalog, map, audio, chatbot…).

Меняйте переменные в `:root`, а не отдельные цвета по всему файлу — так проще поддерживать единый стиль.

### 5.3. Карусель «14 Далай-лам»

| Что | Файл |
|-----|------|
| Тексты, цитаты, чипы слайдов | `js/dalai-carousel.js` — массив `slides` |
| Фотографии | `images/dalai-lamas/Dalai_Lama_1.jpg` … `Dalai_Lama_14.jpg` |
| Разметка блока | `index.html` — секция `.dalai-lamas-section` |

Поле `photo` в слайде — только имя файла; папка задаётся константой `DALAI_PHOTO_DIR`.

### 5.4. Добавить или изменить место на карте

Редактируйте **`data/places.json`**. Пример записи:

```json
{
  "id": "unique-id",
  "name": "Название",
  "coords": [широта, долгота],
  "panoramaCoords": [широта, долгота],
  "type": "святыня",
  "region": "Страна",
  "era": "birth",
  "routeOrder": 1,
  "description": "Кратко",
  "story": "Развёрнутый текст",
  "image": "images/hero.png"
}
```

Поле `era` связано с таймлайном на `map.html` (`birth`, `enlighten`, `teach` и др. — см. существующие записи).  
Карта использует API Яндекс.Карт (ключ в `map.html`).

### 5.5. Добавить видео

1. Загрузите файл в **Yandex Object Storage** (бакет `diplom11` или ваш).
2. Откройте **`video-player.html`**, найдите `window.DHARMA_VIDEO_CATALOG`.
3. Добавьте объект в нужную категорию:

```javascript
{
  "title": "Название ролика",
  "url": "https://storage.yandexcloud.net/.../файл.mp4"
}
```

4. При необходимости добавьте карточку-ссылку на `media.html` или в каталоге.

### 5.6. Добавить аудиотрек (мантру)

В **`audio.html`** найдите массив треков в `<script>` и добавьте элемент с полем `audioUrl` (ссылка на MP3 в облаке). Локальная папка `audio/` в репозиторий не коммитится.

### 5.7. Фоновые лотосы

Логика в **`js/lotus-bg.js`**:

- количество, скорость, цитаты при клике;
- волна и «отталкивание» соседних элементов.

Стили лотосов и волны — секция **LOTUS** в `css/style.css`.  
Цвета лепестков в SVG задаются внутри `lotus-bg.js` (градиенты в `buildLotusSvg`).

Отключить на странице: уберите строку `<script src="js/lotus-bg.js"></script>`.

### 5.8. Настроить AI-наставника

| Файл | Назначение |
|------|------------|
| `js/ai-chatbot.js` | Промпт `CHAT_SYSTEM_PROMPT`, модель, UI чата |
| `js/config.local.js` | Ключ API (локально) |
| `js/site-config.js` | Origin сайта для Referer OpenRouter |

Не коммитьте `config.local.js` в Git.

## 6. Подключение скриптов по страницам

Общий порядок в конце `<body>` (может отличаться):

1. Специфичные для страницы (`catalog.js`, `map-page.js`, `dalai-carousel.js`…).
2. `lotus-bg.js`
3. `site-ui.js` — бургер-меню
4. `back-to-top.js`
5. `site-config.js`
6. `config.local.js` — **без defer**, перед чатом
7. `ai-chatbot.js`

| Страница | Дополнительные скрипты |
|----------|------------------------|
| `index.html` | `scroll-reveal.js`, `dalai-carousel.js` |
| `catalog.html` | `scroll-reveal.js`, `catalog.js` |
| `map.html` | Яндекс.Карты API, `map-page.js` |
| `video-player.html` | `media-videos.js`, каталог в HTML, `video-player-page.js` |
| `media.html` | `media-page.js` |
| `audio.html` | плеер встроен в страницу |
| `kalm.html` | без отдельного page-скрипта (в основном HTML) |

Иконки Lucide: в `<head>` подключается `unpkg.com/lucide`, после загрузки DOM вызывается `lucide.createIcons()`.

## 7. Мобильная версия

- Viewport: `width=device-width, initial-scale=1.0, viewport-fit=cover` на всех страницах.
- Меню ≤768px: кнопка `[data-mobile-nav-toggle]`, панель `[data-mobile-nav-panel]`, фон `[data-mobile-nav-backdrop]` — логика в `js/site-ui.js`.
- Адаптивные стили — блоки `@media` в конце **`css/style.css`** (секция «МОБИЛЬНАЯ ВЁРСТКА»).

## 9. Частые проблемы

| Симптом | Решение |
|---------|---------|
| Чат не отвечает | Проверьте `config.local.js` или секрет `OPENROUTER_API_KEY` на GitHub |
| Карта пустая | Откройте сайт через HTTP; проверьте `data/places.json` и консоль браузера |
| Видео/аудио не играют | Проверьте URL в облаке, CORS и доступность файла по прямой ссылке |
| Стили «не те» | Очистите кэш; убедитесь, что подключён `css/style.css` |
| Лотосы мешают кликам | Кликабельны только сами лотосы; контент поверх — `z-index` в CSS (см. комментарии в `style.css`) |
